# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Preferred reporting method:

- Use **GitHub Security Advisories** (Repository → Security → Advisories → “Report a vulnerability”).

If advisories are not enabled for this repo, open a minimal issue that says you have a security report and ask for a private contact channel (do not include exploit details in the issue).

## What to Include

To help us triage quickly, include:

- A clear description of the issue and potential impact
- Steps to reproduce (or a proof of concept)
- Affected area (backend/frontend/scripts) and any relevant endpoints
- Suggested remediation, if you have one

## Supported Versions

Security fixes are typically applied to the default branch and the latest tagged release (if any).

## Disclosure

We’ll coordinate a responsible disclosure timeline with the reporter when possible.
